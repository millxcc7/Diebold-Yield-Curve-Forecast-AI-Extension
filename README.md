# Diebold–Li Yield Curve Forecast: AI Extension

Replicating Diebold & Li (2006) on U.S. Treasury yields (FRED), extended with
LLM sentiment (FOMC) and gradient boosting.

## Folders

- data/: yield data
- explore/: notebooks for testing
- main_model/: final model code

## Other Folders

- gitignore/: what Git shouldn't upload to Github (.env/: your viru) (**pycache**/: junk that regenerates every run) (.ipynb_checkpoints/: autosave backups jupyter)
- Requirements.txt/: libraries that are used for this project
